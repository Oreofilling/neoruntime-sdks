NeoRuntime C++ SDK

C++ 客户端 SDK,与 Python SDK(python/neoruntime_ipc_sdk)逐模块对等;图像与张量使用 OpenCV cv::Mat(对应 Python 侧的 numpy)。应用运行于设备端的应用容器内,通过本机 Unix Domain Socket 与平台守护进程通信。

模块总览

共享值类型位于 types.hpp;端点与环境变量配置位于 config.hpp。

底层传输

  • gRPC over UDS — 推理、设备、相机、应用、事件、叠加、插件发现。C++ 侧使用同步 stub;Python 版的后台 asyncio 线程机制未移植(同步 stub 本身即阻塞等待,无忙轮询)。
  • 裸 UDS + SCM_RIGHTS fd 传递 — FdMediaClient。收到的 DMA-BUF 平面 fd 按平面 mmap 进 cv::Mat,实现真零拷贝。
  • 裸 UDS、长度前缀帧 — EncodedStreamClient、AudioStreamClient。紧凑线格式结构与 Python 版逐字段对齐。

快速上手

要求:C++17、CMake ≥ 3.20、vcpkg 清单模式(protobuf、grpc、opencv4 无界面构建、nlohmann-json)。

# 本机构建(x86_64 开发机 / CI)
cmake -S cpp -B build-x64 -DCMAKE_BUILD_TYPE=Release
cmake --build build-x64 -j && ctest --test-dir build-x64

# 交叉编译(aarch64 设备)
cmake -S cpp -B build-arm64 \
  -DCMAKE_TOOLCHAIN_FILE=$VCPKG_ROOT/scripts/buildsystems/vcpkg.cmake \
  -DVCPKG_CHAINLOAD_TOOLCHAIN_FILE=$PWD/cpp/cmake/aarch64-toolchain.cmake \
  -DVCPKG_TARGET_TRIPLET=arm64-linux
cmake --build build-arm64 -j

构建选项:NE503_BUILD_EXAMPLES(默认开)、NE503_BUILD_TESTS(默认开)、NE503_REGEN_PROTOS(默认开 — 构建时从仓库根共享的 proto/ 重新生成 stub)。

示例与测试

examples/ 移植了全部 Python 示例:person_detection(流式推理 + 事件发布,入门示例)、perimeter_guard、video_processor、event_subscriber,以及 connectivity_smoke / media_smoke 两个设备端连通性冒烟检查。

GoogleTest 测试套件镜像 python/tests/ 中不依赖守护进程的部分:环境变量配置、推理值类型、媒体/音频线格式结构、AudioFrame 解码,以 ctest 运行。
